# Boutique Afrique Style

Site vitrine e-commerce réalisé en équipe dans le cadre du TP **Travailler en équipe avec Git et GitHub** (HTML5, CSS3, JavaScript).

## Fonctionnalités
- **Page d'accueil (`index.html`)** : présentation de la boutique et accès rapide au catalogue.
- **Catalogue (`catalogue.html`)** : grille de 6 produits artisanaux avec ajout au panier dynamique en JavaScript.
- **Contact (`contact.html`)** : formulaire interactif avec validation des champs en JavaScript.
